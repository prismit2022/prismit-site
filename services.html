Webサイト制作

現在はBlazorを中心に、Next.js / Reactなど幅広い技術に対応しています。直近では、請求・売上・支払・入金などの業務システムをBlazorで開発しています。Webサイトだけでなく、こうした業務用のWebシステムまで一貫して構築できるのが強みです。要件定義から実装まで、まとめてご相談いただけます。

過去に開発した飲食店向けWebシステムでは、お客様からの注文を受け付け、厨房のスタッフにひと目でわかる形で表示する仕組みや、会計機能まで備えたシステムを構築。Next.jsによるフロントエンド設計・実装や、AWSなどのクラウドサービスを用いたインフラ構成の設計を担当してきました。

  • 請求・売上・支払・入金システム
  • 飲食店向けWebシステム
  • Blazor
  • Next.js
  • React
  • AWS

はじめてのご依頼で不安な方も、丁寧にヒアリングしながら進めますので、まずはお気軽にご相談ください。

システム開発

C#.NET / VB.NETを中心とした16年以上の実績があり、要件定義から詳細設計・実装・テストまで一貫して対応します。

放送機器の操作・制御ソフト開発では、あらかじめスケジュールを組んでおくと、指定した時間になると自動で放送が始まるシステムなど、HMI(現場の作業者が機器を操作するための画面)開発や、モーターやセンサーなどの制御を含むTCP/IP・CAN通信を用いた制御ソフトの設計・実装を担当。半導体MESシステムや生産工程解析システムの開発では、OracleやDockerを活用したデータ基盤の設計・実装にも携わり、UMLを使ったわかりやすい設計ドキュメントの作成も行っています。

  • 放送機器制御システム
  • 半導体MESシステム
  • 生産工程解析システム
  • C#.NET
  • VB.NET
  • UML
  • TCP/IP
  • CAN通信
  • Docker

専門的な内容も、現場の状況をしっかりお伺いしたうえで、わかりやすい形にしてご提案します。
